# Boiling Point Predictor — Deployment Guide

This folder contains a complete, working app that predicts the normal
boiling point of an organic compound from its SMILES string, using your
trained LightGBM model.

## What's in this folder

| File | What it is |
|---|---|
| `app.py` | The Streamlit web app (the interface people interact with) |
| `predictor.py` | The core logic: SMILES → descriptors → scaled → prediction |
| `best_model_lgbm.pkl` | Your trained LightGBM model |
| `scaler.pkl` | The fitted StandardScaler (reconstructed exactly from your checkpoint) |
| `feature_names.pkl` | The 10 descriptor names, in the correct order |
| `ad_reference.pkl` | Applicability domain reference data (h*, sigma, training points) |
| `requirements.txt` | The Python packages needed to run the app |

**Do not rename or move these `.pkl` files** — `app.py` expects them in the
same folder.

## Option A: Run it on your own computer (fastest way to test)

1. Install Python 3.10+ if you don't have it already.
2. Open a terminal in this folder and run:
   ```bash
   pip install -r requirements.txt
   ```
3. Then run:
   ```bash
   streamlit run app.py
   ```
4. Your browser should open automatically to `http://localhost:8501` —
   that's your app, running locally.

## Option B: Deploy it online for free (so others can use it too)

**Streamlit Community Cloud** is the easiest free option:

1. Create a free account at https://share.streamlit.io (sign in with GitHub).
2. Create a new GitHub repository and upload everything in this folder to it
   (all 8 files listed above).
3. On Streamlit Community Cloud, click "New app," pick your repository, and
   set the main file to `app.py`.
4. Click "Deploy." After a few minutes you'll get a public link
   (like `yourapp.streamlit.app`) that anyone can open in a browser — no
   Python installation needed on their end.

**Note:** your `.pkl` files don't contain any DIPPR data directly — they're
just the fitted model and scaler numbers — so it's safe to upload them to a
public GitHub repo.

## Known limitations to keep in mind

- **3D embedding can occasionally fail.** A small fraction of molecules
  can't have a 3D conformer generated by RDKit; the app will show a clear
  error message rather than a wrong prediction in that case.
- **Applicability domain (AD) warnings matter.** When the app flags a
  compound as "outside domain," the prediction is a real extrapolation and
  should be treated with real caution, not just a formality.
- **Compounds that decompose, sublime, or don't have a clean boiling point**
  (e.g. many drug-like solids) will still get a numeric prediction — the
  model can't know that a compound doesn't actually boil. Use chemical
  judgment alongside the AD flag.
